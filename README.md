# LilyGO T-Relay-S3 2.4 Display UI

ESP32-S3 relay controller with touchscreen interface.

## Features
- 6 relay control
- Touchscreen UI (ILI9341 + XPT2046)
- MQTT support
- OTA updates
- Neon-style interface

## Hardware
- LilyGO T-Relay-S3
- ILI9341 2.4"
- XPT2046 Touch
